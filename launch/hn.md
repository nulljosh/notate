Show HN: Voxprint – on-device Whisper transcription for iPhone and Mac

Voxprint runs WhisperKit locally, so audio is decoded on the phone or Mac and never leaves it. It transcribes live from the microphone in two second windows, re-decoding only the trailing eight seconds each tick so latency stays flat as a recording grows. Models are picked by device memory and copied out of the purgeable HuggingFace cache into Application Support so they survive storage pressure. Live dictation is free and unlimited; the first three file transcriptions are free too, then it's $0.99 once to unlock the rest. Source is on GitHub and there is a web build at voxprint.heyitsmejosh.com.
